# 0x15. JavaScript - Web interactive

Frontend JavaScript exercises for SE 300: High Level Programming II.

## Learning Objectives
- Manipulate DOM elements with vanilla JavaScript
- Handle browser events (click, keydown)
- Fetch remote data using `fetch()` with `async/await` and handle errors with `try/catch`
- Manage state in JavaScript arrays and re-render the DOM

## Tasks

| File | Description |
|---|---|
| `7-script.js` | Fetch character name from Star Wars API and display in `#character` |
| `8-script.js` | Fetch all Star Wars movie titles and list them in `#list_movies` |
| `9-script.js` | Fetch translation for "hello" in French and display in `#hello` (from `<head>`) |
| `100-script.js` | Turn `<header>` text color to red `#FF0000` (from `<head>`) |
| `101-script.js` | Add, remove, and clear list items using an array as single source of truth |
| `102-script.js` | Fetch translation based on language code input on button click |
| `103-script.js` | Fetch translation on button click OR pressing Enter in input field |
