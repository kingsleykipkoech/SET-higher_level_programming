SRP Analysis & Refactoring Solution

1. Identified SRP Violations

The legacy addTask method attempted to perform 4 distinct responsibilities:

  • Task validation & storage: Validating taskFn and pushing into this.tasks.
  • Queue State Evaluation: Inspecting queue length to trigger processing (this.tasks.length === 1).
  • Execution Scheduling: Spawning background execution via this._startProcessing().
  • Notification & Alerting: Console output and high-priority alerts via notify().

2. Refactored Implementation (Extracted Notifier & Clean Queue)

class QueueNotifier {
  notifyQueueStarted(queueName) {
    console.log(`Starting queue ${queueName}.`);
  }
  notifyHighPriorityTask(queueName, priority) {
    if (priority > 9) {
      console.warn(`High priority task added to ${queueName}.`);
    }
  }
  logError(message) {
    console.error(message);
  }
}

class TaskQueue {
  constructor(name, notifier = new QueueNotifier()) {
    this.queueName = name;
    this.tasks = [];
    this.isProcessing = false;
    this.notifier = notifier;
  }

  addTask(taskFn, priority = 0) {
    if (typeof taskFn !== 'function') {
      this.notifier.logError('Task must be a function.');
      return false;
    }
    this.tasks.push({ taskFn, priority, timestamp: Date.now() });
    if (priority > 9) {
      this.notifier.notifyHighPriorityTask(this.queueName, priority);
    }
    return true;
  }

  startProcessing() {
    if (this.isProcessing || this.tasks.length === 0) return;
    this.isProcessing = true;
    this.notifier.notifyQueueStarted(this.queueName);
    while (this.tasks.length > 0) {
      const current = this.tasks.shift();
      try { current.taskFn(); } catch (e) { this.notifier.logError(e.message); }
    }
    this.isProcessing = false;
  }
}

3. Architectural Benefits

  • Enhanced Testability: addTask can now be tested in pure isolation without side effects (no automatic task execution or polluted console logs). Mock notifiers can be injected via the constructor.
  • High Modularity & Maintainability: Changes to logging destinations (e.g. shipping logs to Datadog or Slack) only touch QueueNotifier, leaving core queue logic untouched.
  • Resolved Scope Bug: name was replaced with this.queueName, eliminating the runtime ReferenceError.
