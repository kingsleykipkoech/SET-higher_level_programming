# 0x12. JavaScript - Warm up

JavaScript scripting exercises for SE 300: High Level Programming II.

## Environment
- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard 16.x.x

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-javascript_is_amazing.js` | Print "JavaScript is amazing" |
| 1 | `1-multi_languages.js` | Print 3 lines |
| 2 | `2-arguments.js` | Print message based on argument count |
| 3 | `3-value_argument.js` | Print first argument |
| 4 | `4-concat.js` | Print two arguments in a sentence |
| 5 | `5-to_integer.js` | Print integer value of argument |
| 6 | `6-multi_languages_loop.js` | Print 3 lines using a loop |
| 7 | `7-multi_c.js` | Print "C is fun" x times |
| 8 | `8-square.js` | Print a square of X characters |
