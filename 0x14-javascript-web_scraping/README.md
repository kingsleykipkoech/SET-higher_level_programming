# 0x14. JavaScript - Web scraping

JavaScript web scraping exercises for SE 300: High Level Programming II.

## Environment
- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard 16.x.x

## Requirements
- Install request module: `sudo npm install request --global`
- Set path: `export NODE_PATH=/usr/lib/node_modules`

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-readme.js` | Read and print file contents in utf-8 |
| 1 | `1-writeme.js` | Write a string to a file in utf-8 |
| 2 | `2-statuscode.js` | Display status code of a GET request |
| 3 | `3-starwars_title.js` | Print Star Wars movie title by episode ID |
| 4 | `4-starwars_count.js` | Count movies where Wedge Antilles appears |
| 5 | `5-request_store.js` | Fetch webpage content and store in a file |
| 6 | `6-completed_tasks.js` | Compute completed tasks count per user |
